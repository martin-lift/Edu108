AI режимът изисква настроен Teacher108; JSON не съдържа ключове. Няма времеви лимит и е разрешено връщане назад. Не се изисква файл за предаване, защото работата се предава като отговори в стъпките.

В учебния текст няма препратки към други уроци. В урока няма връзка към мисията. Не е възлагана мисия на реални ученици.
