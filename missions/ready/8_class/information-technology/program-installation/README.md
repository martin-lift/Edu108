# Инсталиране и деинсталиране на програми

Стандартна мисия по урок 11, стр. 33–36 от [учебника по ИТ за 8. клас, Домино](https://ebook.domino.bg/books/8/it/#page=33).

20 стъпки. Съдържанието е за начинаещи ученици. Изображенията са оригинални схеми на конкретни примери, публикувани с външни URL; не се представят за екранни снимки на реален ученически компютър. Отворените отговори имат предварителна обратна връзка; AI е изключен.

## Покритие на урока

- Стр.33: приложен софтуер, авторски права/лиценз, free software/freeware/shareware/adware/trial/demo/freemium, инсталационен и преносим софтуер, изисквания и Setup.
- Стр.34: цялата последователност от примера Bandizip: файл, език, папка, лиценз, настройка за потребители.
- Стр.35: Control Panel/Programs and Features/Uninstall, OpenOffice; задачите са обяснени примери.
- Стр.36: хардуерни/софтуерни проблеми, Device Manager/Properties, Task Manager/Processes/End Task; IZArc и сравняване на софтуер са включени.

## Източници за проверка

- [GNU: категории софтуер](https://www.gnu.org/philosophy/categories.html)
- [GNU: свободен софтуер](https://www.gnu.org/philosophy/free-sw.html)
- [Microsoft: премахване на приложения](https://support.microsoft.com/en-us/windows/uninstall-or-remove-apps-and-programs-in-windows-4b55f974-2cc6-2d2b-d092-5905080eaf98)
- [Bandizip](https://www.bandisoft.com/bandizip/)
- [Apache OpenOffice](https://www.openoffice.org/)

Поправени обобщения: freeware не забранява винаги копиране; free software може да е платен; adware/freemium не са непременно подвидове на shareware; демонстрациите имат различни ограничения; Program Files не е единственото място за всяка програма. Старият инсталационен файл е описан исторически, а не предложен за изпълнение.
