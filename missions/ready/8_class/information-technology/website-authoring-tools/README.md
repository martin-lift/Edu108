# Специализирани софтуерни средства за създаване на уеб сайтове

Стандартна мисия по урок 16, стр. 46–47 от [учебника по ИТ за 8. клас, Домино](https://ebook.domino.bg/books/8/it/#page=46).

20 стъпки. Съдържанието е за начинаещи ученици. Изображенията са оригинални схеми на конкретни примери, публикувани с външни URL; не се представят за екранни снимки на реален ученически компютър. Отворените отговори имат предварителна обратна връзка; AI е изключен.

## Покритие на урока

- Стр.46: WWW/хипертекст/HTML/тагове/браузъри/връзки/страница/сайт/история; класификация по цел с всички пет вида; анализ на училищен сайт.
- Стр.47: статичен/динамичен/сървър/данни/шаблон/CMS; всички назовани групи редактори и примери; Google Sites/Wix като готов интерфейсен пример; CSS и навигация, включително приложим анализ на образователен сайт.

## Източници за проверка

- [MDN: HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax)
- [MDN: CSS](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/What_is_CSS)
- [CERN: история на Web](https://home.cern/science/computing/the-birth-of-the-web/short-history-web/)
- [Google Sites: създаване](https://support.google.com/sites/answer/98081)

Поправени абсолютни твърдения: статичен сайт не е непременно по-бърз; видът не се доказва по изглед; блог не изисква форум; първоначални страници1990/публично представяне1991; WebSiteX5 не е общо онлайн редактор. Не се препоръчва инсталиране на неподдържан стар инструмент.
