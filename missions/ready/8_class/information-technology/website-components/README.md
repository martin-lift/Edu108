# Създаване и интегриране на компонентите на сайт

Стандартна мисия по урок 19, стр. 54–56 от [учебника по ИТ за 8. клас, Домино](https://ebook.domino.bg/books/8/it/#page=54).

22 стъпки. Съдържанието е за начинаещи ученици. Изображенията са оригинални схеми на конкретни примери, публикувани с външни URL; не се представят за екранни снимки на реален ученически компютър. Отворените отговори имат предварителна обратна връзка; AI е изключен.

## Покритие на урока

- Стр.54: проектСофия/4страници/4части; папкаwebsite; index/Title/Author/Description/цветове/Preview/Browse; Table2×3/1000px/Border0/Spacing10/Padding5/Center/сивфон/150px/200px.
- Стр.55: герб/заглавие/девиз/статуя/центриране; меню/основентекст/изображение/външнивръзки/автор/година.
- Стр.56: вътрешни файлове geography/history/cathedrals; копиране на таблица; тематични текстове; Serdica/WrapLeft/5px/Border0; вътрешни и външни връзки; личен тематичен сайт.
