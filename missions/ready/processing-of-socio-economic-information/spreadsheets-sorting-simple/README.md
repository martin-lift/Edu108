# Електронни таблици — сортиране по име

Опростен вариант за 12. клас по [урока „Електронни таблици — сортиране“](https://martin-lift.github.io/108/Processing%20of%20Socio-Economic%20Information/03-Spreadsheets-Sorting.html).

- [Готова мисия — JSON](spreadsheets-sorting-simple.json)
- [Изчистен работен файл](sorting-simple.xlsx)
- [Директен JSON за Student108](https://raw.githubusercontent.com/martin-lift/Edu108/main/missions/ready/processing-of-socio-economic-information/spreadsheets-sorting-simple/spreadsheets-sorting-simple.json)

Пет стъпки: „За какво е този урок?“, изтегляне и отваряне, една задача за сортиране, записване, предаване на файл. Разрешено е връщане назад; няма времеви лимит.

Единствената задача е сортиране на целия диапазон A1:B6 по „Име“ във възходящ ред. Файлът съдържа само лист „Ученици“ с пет измислени учебни записа и две колони. Начален ред: Елена, Борис, Георги, Алекс, Виктория. Очакван ред: Алекс, Борис, Виктория, Георги, Елена. Резултатите от теста остават съответно 84, 72, 93, 79, 91.

Всички задачи и обяснения са в мисията; в работния файл има само таблицата. Указанията обхващат Excel и LibreOffice Calc, маркиране на целия диапазон, настройка за заглавия, един критерий, самопроверка, записване в Documents (Документи) и бутона „Избери файл ...“.

Предава се един файл „Сортиране-Име-Фамилия.xlsx“. Пълната мисия с осем задачи остава отделно в папка `spreadsheets-sorting`.

Проверени са JSON схема 4 с валидатора на Student108, началният ред, размерът и чистотата на таблицата, очакваното подреждане с целите записи и визуалното оформление. Реалният интерфейс на Student108 не е тестван в тази сесия.
