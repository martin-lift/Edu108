# Електронни таблици — сортиране

[Директно изтегляне на мисията](https://raw.githubusercontent.com/martin-lift/Edu108/main/missions/ready/processing-of-socio-economic-information/spreadsheets-sorting/spreadsheets-sorting.json)

Готова мисия по **схема 4** за Teacher108 и Student108, създадена по [урок 03](https://martin-lift.github.io/108/Processing%20of%20Socio-Economic%20Information/03-Spreadsheets-Sorting.html), версия `martin-lift/108` commit `75fd36a38c975df65a47c2f5805abe280d5722f4`. Тази папка съдържа само готовата мисия и настоящото описание.

Мисията има **17 стъпки**. Първата е „За какво е този урок“. Следват обяснения, изтегляне и записване на работния файл, осемте задачи и проверка на всички резултати. Последната стъпка е предаване на файл с поддържания тип `file`.

1. За какво е този урок
2. Какво е сортиране?
3. Една колона: възходящ ред ASC и низходящ ред DESC
4. Изтеглете и запишете работния файл
5. Маркирайте целия диапазон
6. Задача 1. Сортирайте по име възходящо — ASC
7. Задача 2. Сортирайте по име низходящо — DESC
8. Задача 3. Сортирайте по числова колона — успех DESC
9. Как работи сортирането по няколко колони?
10. Задача 4. Подредете по клас и успех
11. Задача 5. Подредете по град и отсъствия
12. Задача 6. Разрешете равенство с втори критерий
13. Задача 7. Проверете целостта на записите
14. Задача 8. Използвайте потребителски ред на градовете
15. Проверете всички запазени резултати
16. Запазете готовата работна книга
17. Качете готовия файл

Учебният текст, указанията за Excel и LibreOffice Calc, условията и самопроверките от всички 15 стъпки на урока са запазени. Добавени са въвеждаща стъпка, изрично начално записване на работен файл и последна стъпка за качване. Обяснението за ASC/DESC е преди изтеглянето, а задачите по една колона са преди сортирането по няколко критерия.

Работният файл се изтегля от [публичната връзка в урока](https://martin-lift.github.io/108/Processing%20of%20Socio-Economic%20Information/03-sorting-practice.xlsx). Ученикът предава една `.xlsx` работна книга с всички 10 листа: „Ученици“, „Задачи“ и „Таблица 1“–„Таблица 8“. Всяка задача запазва отделния си резултат и отговор в A19. Няма времеви лимит и е разрешено връщане назад.

Проверки: валидатори на Teacher108 и Student108, съответствие с текста на урока, HTML структура и абсолютни връзки, ред на задачите, прилагане на файл с проверка на съдържанието и SHA-256, възстановяване на прикачения файл в модела на Student108. Не са изпращани резултати или мисии към реални ученици.
